URBAN ATLAS / EDITION 02
Architectural exhibition theme — forest, paper, chartreuse and orange.

MAMOSTAYAN / URBAN INTELLIGENCE
40-scene architectural presentation

OPEN THE PRESENTATION
1. Extract the complete ZIP. Do not open index.html from inside the ZIP viewer.
2. Open the extracted MAMOSTAYAN_URBAN_PRESENTATION folder.
3. Double-click index.html. Use a desktop browser with JavaScript enabled.
4. Press F for fullscreen. On Windows, F11 also opens browser fullscreen.

No internet, server, account, installation, or build step is needed by the code.
Keep the css, js, assets, source and documentation folders beside index.html.

QUICK CONTROLS
Right arrow / Space / Page Down     Next scene
Left arrow / Backspace / Page Up    Previous scene
Home / End                         First / last scene
O                                  Scene overview / chapter index
S                                  Source notes for the current physical PDF page
F                                  Fullscreen
P                                  Presenter mode (hide / restore the interface)
R                                  Reduced motion on / off
H or ?                             Help
Escape                             Close image / detail / overview

The arrow buttons and chapter rail also navigate. Navigation never waits for
an animation. The introduction is skipped by advancing to the next scene.
On touchscreens, swipe over empty slide space or use the navigation arrows.
Landscape orientation makes the slides larger.

INSPECT THE EVIDENCE
Click any photograph or map for an enlarged viewer.
Scroll or pinch to zoom, drag to pan, and use FIT or double-click to reset.
The viewer always shows the original caption and source reference.

Select any cell in the evaluation matrices on scenes 23 and 38 to inspect
that exact policy, its purpose, source photo, observation and score.
Select OPEN SCENE in the detail view to return to its original scene.

On scene 5, select the first two observations to inspect the corresponding
area of the original master plan. The third observation opens the tower
photograph; no unsupported tower location is marked on the plan.

On scenes 24 and 39, toggle between the unchanged observed photograph and
a separate PROPOSED IMPROVEMENT concept diagram. The diagram is not a survey
or a claim about completed works.

VISUAL INDEX
Double-click OVERVIEW.html for a standalone contact-sheet-style visual index
of all 40 redesigned scenes. Select a thumbnail to open that scene.
The same index is available inside the presentation by pressing O.

ACCURACY
There are 10 policies per principle and 40 policies in total.
Physical PDF page 38 governs the evaluation:
Mixed Land Use 5.5; Compact Building Design 6;
Walkability 6.5; Transportation Options 3.5.
Total: 21.5 / 40. 19 available + 5 unsure + 16 not available.
This is policy availability, not a percentage rating of urban-design quality.

The source cover provides no team names after PREPARED BY; none were invented.
All source photographs remain unretouched, uncropped and correctly paired.
Source resolution limits remain; enlargement does not create extra detail.

VERIFICATION STATUS
JavaScript syntax, all 40 generated scenes, policy completeness, matrix sums,
image identities, local dependencies and ZIP integrity were checked.
Font-metric checks found no estimated overflow in the policy text areas.

A real Chrome/Chromium launch was attempted, but the authoring environment
has no installed browser executable. Browser screenshots, direct file://
execution, input interactions, performance and projector appearance could
not be verified here. The QA report distinguishes these unrun checks.
Open index.html on the presentation laptop before presenting.

EDITING
Content and score records: js/presentation-data.js
Scene compositions: js/slides.js
Typography, palette and layout: css/main.css and css/presentation.css
Motion sequences: js/animations.js and css/animations.css
Navigation / overlays: js/app.js and js/interactions.js

The code uses classic local script files, CSS, SVG and the browser animation
API. It has no remote libraries, JSON fetches, ES-module imports or map tiles.
